# 盲测记录与失败案例修订说明

## 测试设置

测试者先只查看 `review_text`，按 `SKILL.md` 独立填写标签，再运行 `src/consumer_insight.py` 生成基线结果。对照时以原文证据为准；“unknown”计为合规结果，不强行追求有标签。

## 失败案例

1. “降噪是有，但戴半小时耳朵像被夹住，价格也不便宜。”首版只命中“降噪”，遗漏佩戴痛点和价格阻碍。修订为先扫描负面词，再从证据片段分别识别 `pain_point` 与 `purchase_barrier`。
2. “这音质，真是‘好’到我想关掉。”首版因出现“好”误判 positive。修订说明：反讽无法由关键词可靠判断，改为 `sentiment=unknown` 或 `confidence=low` 并进入人工复核；本基线实现保守返回 low。
3. 空评论首版输出空字符串，违反字段稳定性。修订为所有枚举字段返回 `unknown`，`evidence=unknown`，`confidence=low`。
